# Technical SEO Basics (per-project gate)

- [ ] Unique title/meta-description per page; heading hierarchy one-h1, logical order
- [ ] Canonical URLs; clean params handling; no soft-404s
- [ ] sitemap.xml + robots.txt (don't block CSS/JS rendering assets)
- [ ] OpenGraph + Twitter cards for share surfaces
- [ ] Structured data where honest (Organization, Product, FAQ — never fake reviews)
- [ ] CWV pass (ranking-coupled user signals; see performance/core-web-vitals.md)
- [ ] SSR/SSG for content pages (JS-only rendering = invisible content risk; verify crawler rendering with current tooling)
- [ ] Internal linking meaningful; image alt text real
