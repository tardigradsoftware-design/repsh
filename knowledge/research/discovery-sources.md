# Discovery Sources & Search Terms

## Where to look (priority order)
GitHub (official orgs → topics → trending), official documentation, arXiv (+ Papers-with-code lineage), Hugging Face (models/datasets/spaces/leaderboards), npm/PyPI (download trajectories as adoption signals), MCP ecosystem directories, conference proceedings (NeurIPS/ICLR/ICML/ACL), engineering blogs of verified organizations.

## Standing search terms (extend, don't limit)
AI agent skills · coding agent skills · agent instructions · agent memory · context engineering · agentic coding · browser agents · computer use agent · MCP servers · AI coding workflow · LLM evaluation · agent benchmark · reasoning benchmark · tool use benchmark · LLM system prompts research · prompt engineering · LLM security · agent security · AI software engineering · process reward models · test-time compute · RLF/RLVR reasoning training

## Discovery hygiene
- New ≠ valuable: run the full source-validation gate before ANY record.
- Trending is a lead, not a verdict (star-farm awareness).
- Keep vendor claims in QUOTES with dates until independently verified.
