# Görev 08: Dashboard Sipariş Listesi
## Açıklama
Sipariş listesi sayfası: sunucu tarafı sayfalama, durum/arama/tarih filtresi, toplu durum güncelleme.
## Başarı
- Tablo: sipariş no, müşteri, tutar, durum, tarih
- Filtre URL'de (sayfa yenilince kalıyor)
- Tutar formatı ₺1.234,56; tarih DD.MM.YYYY HH:mm
- Durum rozeti renk+ikon+metin (sadece renk değil)
- Toplu seçim + altta floating bar ("N sipariş seçildi")
- Loading/empty/error durumları
- 200+ sipariş veri ile kayma/sıkışma yok; pagination doğru
