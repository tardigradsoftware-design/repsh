# Görev 15: Dark Mode Uygulaması ve Tasarım
## Açıklama
Mevcut dashboard'a dark mode ekle. CSS değişkenleri üzerinden.
## Başarı
- Tüm renkler CSS değişkeni üzerinden; hardcode renk kalmamış
- Light/dark arasında geçiş düzgün; `prefers-color-scheme` destekli; localStorage tercihi
- Dark modda kontrast 4.5:1 (koyu gri + hafif renk, saf siyah değil)
- Grafikler/kartlar/kod blokları dark modda okunuyor
- Resim/illüstrasyonlar dark moda uyumlu (gerekirse farklı varyant)
- Geçiş animasyonu ölçülü (150ms); reduced-motion destekli
