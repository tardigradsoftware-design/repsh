# Model Claim Verification Checklist

Before trusting ANY model capability claim (vendor blog, benchmark, your memory):
- [ ] Exact model VERSION (families have many variants with different behavior)
- [ ] Claim source + date (vendor claim ≠ independent measurement)
- [ ] Benchmark vintage + contamination notes (evaluations/reasoning/benchmarks.md)
- [ ] YOUR task eval (≥30 cases) — public benchmarks only shortlist
- [ ] Structured-output/tool-use reliability measured, not assumed (breaks differ per version)
- [ ] Prompting guidance from CURRENT official guide (techniques age per model family)
