# Copy Policy

## Never copy wholesale
External READMEs/docs/code → we store: summary, key concepts, why useful, when useful, limitations, URL, license, verified date.

## License rules
- Record SPDX id; `CUSTOM/NOASSERTION` when non-standard (then LINK, don't embed)
- No license = no redistribution, period. Link-only records.
- Quoting: short excerpts with attribution acceptable under fair-use norms; code never vendored without permissive license.

## Attribution
Every reference record names its source org/author. This repo's own content: MIT, but referenced items keep their licenses.
