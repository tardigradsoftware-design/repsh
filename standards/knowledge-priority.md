# Knowledge Priority

```
Official source > Maintainer documentation > Research paper >
Tested implementation > Community consensus > Individual opinion
```

- "Official" = the canonical org of the project/standard (verified via repositories/ records).
- Multiple independent credible sources agreeing upgrades confidence one level (max VERY HIGH).
- Vendor claims about their own products = authority for WHAT it is, RECOMMENDATION-grade for whether it's good.
- AI-generated content is NEVER above individual opinion in this hierarchy (usually: GENERATED, unverified).
