# Common Mistakes (agents using or building on LLMs)

1. Stars-as-quality — popular ≠ maintained ≠ licensed (run source-validation)
2. Reinventing mature libraries (build-vs-reuse check skipped)
3. Invented dependencies/APIs (verify package names on the registry before install)
4. Trusting training-data versions ("as I remember it" APIs)
5. Context stuffing instead of retrieval (attention dilution)
6. Mock-only test suites that test the mocks
7. Security review deferred to "after launch"
8. Copying competitor pixels instead of principles (stale + incoherent + infringing)
9. Recording AI guesses as facts in KBs (GENERATED tag exists for a reason)
10. Hiding conflicting evidence to seem decisive
11. Optimizing before measuring
12. One mega-prompt instead of structured modular prompts
