# Anti-Patterns

Failure knowledge is first-class here — often more valuable than success examples.

- `known-bugs.md` — stack gotchas by error class (searchable)
- `common-mistakes.md` — recurring agent/AI mistakes
- `catalog.md` — named anti-patterns with symptoms/fixes

Contribution rule: a real reproduction (seen in the wild), not a hypothetical. Each entry: symptom → cause → fix → prevention.
